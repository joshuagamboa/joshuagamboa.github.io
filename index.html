turboquant-apple-silicon

A production-grade Rust integration that brings aggressive KV cache quantization to Apple Silicon GPUs (M1/M2/M3/M4/M5). By wrapping a specialized fork of llama.cpp, this project enables significantly reduced memory footprints for large models and long-context windows without sacrificing the power of Metal acceleration.
